## 公司简介

佛山梅斯睿蒂科技有限公司致力于供暖系统配套产品的研发、生产和销售。其研发团队早在 2000 年就开始研究塑料管道系统的配套产品，是国内最早一批研究塑料管路系统和分集水器的团队，有丰富的产品研发应用经验。

## 主营产品

- 去耦罐、耦合罐、水力分压器
- 黄曲霉素降解机
- 不锈钢分水器、混水缸、混水器、混水罐
- 模块式 PPO 全塑分集水器
